# Shared logins, not individual accounts

Each shelter has one login shared by its front desk, all caseworkers share one caseworker login, and Admin (Marcus and Renee) has a separate login. We rejected individual accounts because front desk turnover is high and training must take under ten minutes, so keeping per-person accounts up to date would not happen. Because the caseworker login is shared, a caseworker types their first name when placing a hold, and the browser remembers it. That name is a staff name, which the privacy rule allows. Front desk actions are attributed to "[Shelter] front desk", not to a person. The Admin login is separate from the caseworker login so that a caseworker cannot change a shelter's capacity or eligibility rules by accident during a call. With shared passwords, Admin changes a shelter's password whenever a front desk worker leaves.
